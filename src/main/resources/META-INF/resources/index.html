Hello World!

A small Quarkus app for demonstrating JDK Flight Recorder and Cryostat.

Say hello

  • /api

    Returns a greeting with the current time.

  • /api/hello/World

    Greets whoever you name. Change World in the address to any name.

Cause a problem to record

  • /api/leak

    Keeps 1 MB more in memory with every request, until you restart the app.

    Find it with jdk.OldObjectSample

  • /api/garbage

    Creates 2 million short-lived strings per request, so garbage collection runs more often.

    Find it with jdk.ObjectAllocationSample and jdk.GarbageCollection

  • /api/contention

    Holds a shared lock for 100 ms, so requests wait in line. Send several at once to see the slowdown.

    Find it with quarkus.Rest and jdk.JavaMonitorEnter

Record your own event

  • /api/event

    Records a custom event with a message, timed around a 42 ms pause.

    Find it with com.test.HelloWorld
